# How to install

### PrismLauncher
1. Download official TerraFirmaGreg-Modern modpack from CurseForge
2. Download latest [packwiz-installer-bootstrap](https://github.com/packwiz/packwiz-installer-bootstrap/releases)
3. Copy `packwiz-installer-bootstrap.jar` to `minecraft` folder (with mods, configs inside)
4. Click on modpack instance -> `Edit` (right side menu) -> `Settings`
5. In `pre-launch command` field enter `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/Hronon/TFG-Modern-Custom/main/pack.toml`
6. Launch the game
